// projects

Manimator MVP frontend · core

The unified interface for the nabin2004 stack. Runs the full system via Docker Compose — Manimator backend, Dagestan memory layer, and the web UI, all wired together in one container network.

$ git clone https://github.com/nabin2004/manimator-mvp
GitHub localhost:3000
Manimator multi-agent · RL

A multi-agent pipeline for generating educational Manim animations, framed as a search problem with a multi-objective reward function. Uses Qwen2.5-Coder-14B with multiple LoRA adapters (planning, coding, repair) and SmolVLM-2B as a frozen visual reward model.

$ git clone https://github.com/nabin2004/manimator
GitHub HuggingFace
Dagestan memory · KG

Temporal knowledge graph memory system for LLMs. Dynamic schema induction, temporal decay, contradiction detection, and hybrid graph+vector retrieval. Ships as a PyPI package. Targeting the MemAgents workshop at ICLR.

$ pip install dagestan
GitHub PyPI

// what the installer does

01

Checks your environment

Verifies git and docker are installed and the Docker daemon is running. Fails fast with a clear error if not.

02

Clones Manimator MVP

Clones the repo into ~/.nabin2004/manimator-mvp. If already installed, pulls the latest changes instead.

03

Configures your environment

Copies .env.example → .env so you can drop in your API keys. Won't overwrite an existing config.

04

Spins up the full stack

Runs docker compose up -d --build. Pulls all images, builds containers, starts Manimator API, Dagestan, and the MVP frontend.

05

Prints access URLs

Manimator MVP UI at localhost:3000 · Manimator API at localhost:8000 · Dagestan at localhost:8001
